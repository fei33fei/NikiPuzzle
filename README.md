# NikiPuzzle

只做拼图的本地应用。无账号、无外部依赖，照片不会发送到服务器；只有你主动点击“检查更新”时才会连接 GitHub。

## 启动

Windows 双击根目录的 `start.cmd`，会打开独立的 Edge / Chrome 应用窗口。需要 Node.js 18 或以上（当前机器已安装）。也可以运行 `npm start`，再访问 http://127.0.0.1:4173 。不需要 npm install。

## 使用

1. 选择画布比例，也可以输入自定义宽高比。
2. 导入多张照片，或把照片文件拖入窗口。第一次导入自动适配照片数量（每张拼图最多 12 格）。想推倒重来时，点右侧“照片素材”旁的“清空”可一键清掉全部照片，拼图数量与布局保持不变，随时可以 Ctrl+Z 撤销恢复。
3. 选择基础、杂志或异形布局。点击画布格子，然后点击素材可替换该格照片。支持重复使用照片。
4. 把一格里的照片拖到另一格可以换位：目标格有照片时两张互换，目标格为空时照片移过去、原位置留空；拖到空白处则不移动。在同一格内拖动仍然是平移照片位置，按住 Alt / Shift 拖动可强制只平移、不换位。滚轮或右侧滑条缩放；可切换完整显示 / 铺满。调整底色、间距、外边距和圆角。异形格子使用自己的轮廓，圆角适用于矩形格子。
5. “按布局批量生成”会按导入顺序分组生成多张拼图，最后一组自动使用实际照片数量；每张拼图可单独更换比例与布局。点击作品集缩略图切换。
6. 点击右上角“导出拼图”，在弹窗中选择当前或全部、自定义像素、文件名前缀。Edge / Chrome 可选择保存文件夹批量写入 PNG；未选文件夹时单张弹出保存对话框，批量下载一个 ZIP（内含每张独立 PNG）。浏览器下载位置也可在浏览器设置中开启“每次询问保存位置”。

## 检查更新

界面左下角的“设置”里可以查看当前版本并检查更新：

- **检查更新**：读取本机版本号，再向 GitHub 仓库 `fei33fei/NikiPuzzle` 的 `main` 分支询问最新版本号，只有在你点击这个按钮时才会联网。
- **下载并安装**：下载最新源码包，只覆盖应用自身的代码文件（界面、脚本、样式、服务器等），照片、作品和模板都在浏览器本机存储里，不受影响。旧版本会备份到 `.update-backup/` 目录。
- 安装完成后应用会自动重启并重新载入界面。若长时间没有反应，重新运行 `start.cmd` 即可。

服务器只监听本机 127.0.0.1，安装接口需要专用请求头，外部网页无法调用它来改动你的电脑。

## 36 种布局与满铺异形

基础、杂志、异形各 12 种布局。异形包含斜切、折线、阶梯、蜂巢分区、钻石切面、放射扇面、不规则碎片等满幅切分，以及圆形、心形、错层照片叠放。叠放使用第一张照片作为完整背景，其余照片置于上层。点击背景露出的位置可以调整底图。切换异形布局默认将外边距、间距、圆角设为零，保持照片铺满画面；可手动增加间距和外边距。异形轮廓本身不使用矩形圆角。

预览与导出使用相同的照片分区、裁切和叠放顺序，导出的是当前展示的合成结果。选中格子的虚线是操作提示，不会进入导出图片。导出开始时会固定当前作品及尺寸，之后的界面调整不影响正在保存的这一版。

## 全部照片直接长拼

导入照片后，在左侧“04 纵横长拼”中选择“纵向拼贴”或“横向拼贴”，会新增一张包含全部素材的长图，原有作品保留。纵向统一宽度，横向统一高度，按导入顺序完整显示每张照片，照片不裁切、不变形、无间隔、无边框，不受普通布局 12 格的限制（最多 2000 张，仍受浏览器内存限制）。长图预览区域支持滚动查看。追加素材后，点击“用全部素材更新当前长拼”可重新汇总。

长拼会按照片实际比例自动决定画布比例；选择左侧普通布局或画布比例即可把当前长拼切回普通拼图（保留前 12 张，可撤销恢复）。长拼也支持模板与作品保存恢复；套用长拼模板时，有素材则自动使用当前全部素材及其实际比例。

长拼默认推荐“短边 1200 px”，也可选短边 2400、自定义或按长边导出。照片很多时请降低短边或使用自定义像素，以满足单边 30000 像素和总像素 6400 万的上限。该尺寸限制只限制输出像素，不会删除长拼中的照片。

## 保存与恢复

- **保存模板**：保留画布比例、照片格数、布局、底色和间距，存储在当前浏览器的本机存储中。下次启动点击模板一键套用。导出模板 JSON 可跨浏览器或设备备份。模板不包含照片与照片构图。
- **保存作品**：下载 `.nikipuzzle` 文件，包含全部拼图、构图和原始导入照片。下次“打开作品”恢复。原图按 Base64 保存，文件约比原图总量大三分之一。作品不会自动保存，请退出前主动保存。
- 撤销 / 重做支持布局、构图、照片分配、照片换位和页面操作，快捷键 Ctrl+Z / Ctrl+Shift+Z。作品打开会替换当前工作台，请先保存当前作品。

## 高清说明

导出为 PNG **无损编码**，没有 JPEG 一类的有损压缩。PNG 本身会无损压缩数据，文件大小不代表画质损失。拼图会按指定输出像素对原图进行裁切与重采样，放大小原图不会增加原图细节；原始照片可通过保存作品保留。无水印，不进行美颜、滤镜或其他修图处理。

普通拼图默认长边 4800 像素，可选 2400 / 8000、短边 1200 / 2400 或自定义；每边 1–30000 像素，总像素上限 6400 万。为避免大量图片占用过多内存，批量大图建议直接选择文件夹逐张写入。所有照片格填满后才能导出，避免误保存空白作品。

支持浏览器可解码的 JPG / PNG / WebP / AVIF / GIF / BMP。GIF 仅取静态帧。HEIC / RAW 请先转为 JPG 或 PNG。透明照片将合成到所选底色。保留的是拼图像素内容，不会复制相机 EXIF、GPS 或原始色彩配置文件；不保证专业印刷色彩管理。

## 开发与验证

`npm run check` 检查脚本语法；`npm test` 验证布局、模板校验、输出尺寸、裁切、换位规则与 ZIP 数据。服务器仅监听本机 127.0.0.1，除应用静态文件外只提供本机更新接口，不开放用户照片或目录。启动器启动的本地服务会留在后台以便再次打开；如需结束，在任务管理器中结束对应的 `node server.mjs` 进程，或前台运行时按 Ctrl+C。

把新的版本推到这个仓库的 `main` 分支、**并同步提升 `package.json` 里的版本号**之后，所有安装了这个应用的人就能在“设置”里看到新版本。版本号不变时，即使仓库有新的提交也不会提示更新。
